# Mephisto AI

Mephisto is a local-first desktop AI companion built with Electron, React and SQLite. Its cognitive state is modeled computationally; the application does not claim that the software has human consciousness or literal emotions.

## Implemented systems (v0.5.0)

- Persistent Persian-first character identity with the 12 baseline traits, five behavioral layers, inner contradictions, boundaries and context-sensitive speech guidance.
- Separate modeled emotion and relationship engines with bounded dimensions, decay and event history.
- Working conversational context plus persistent memories with confidence, importance, source, status, expiration and last-access tracking; local Ollama embedding vectors and hybrid semantic/lexical retrieval (with lexical fallback if the embedding model is unavailable). Explicit preference statements can be extracted into the memory store.
- Goal tracking, decision logs, reflection records, bounded adaptive personality offsets from repeated explicit feedback, and a 100-scenario personality test corpus.
- Opt-in idle maintenance and proactive conversation with quiet hours, daily limits and minimum intervals. Both are disabled by default; autonomous work runs only while the desktop app is open.
- Provider abstraction for local Ollama and OpenAI-compatible HTTPS APIs. External providers require explicit permission; API keys are encrypted with Electron `safeStorage` where the OS supports it.
- Sandboxed renderer, context isolation, limited preload bridge, input bounds, guarded web ingestion and an external HTTPS REST service manager with encrypted bearer tokens and explicit read/write scopes.
- SQLite persistence and JSON backup export.

## Requirements

- Node.js 20+
- npm
- Ollama for local inference, or an OpenAI-compatible API endpoint if you explicitly enable external-provider permission.

## Local run

```bash
npm install
ollama pull qwen2.5:7b
ollama pull nomic-embed-text
npm run dev
```

Open Settings to choose the provider, URL, chat model and embedding model. The default provider is local Ollama at `http://127.0.0.1:11434`. Semantic memory search uses the local `nomic-embed-text` embedding model by default; install it with the command above. If it is unavailable, the app transparently falls back to weighted lexical retrieval.

## Tests and build

```bash
npm test
npm run build
npm run dist
```

`npm run dist` builds an installer for the current operating system. Build each target OS on its own supported build environment. The source archive includes the full application source; a platform installer is not bundled.

## Privacy and autonomy

Chat, memories, goals, knowledge and cognitive state are stored in the local SQLite database under Electron's user-data directory. Local Ollama requests remain on the configured local endpoint. If an external provider is selected and permission enabled, the prompt context (recent conversation, relevant memories, active goals and reference snippets) is sent to that provider. API keys are stored using Electron safeStorage when available; the application refuses to save a key if OS encryption is unavailable.

Autonomy, background maintenance and proactive messages are off by default. When enabled, the scheduler operates only while Mephisto is running, observes configured quiet hours, rate limits and message caps, and does not execute arbitrary shell commands. Internet ingestion and file import are separate explicit user actions.

## Known limitations

- Emotion, relationship, preference extraction and reflection are heuristic/computational approximations, not validated psychological models. Adaptive personality changes only from repeated explicit feedback, adjusts bounded trait/style offsets (±10) after repeated explicit feedback or repeated reflection findings, and never rewrites the immutable core identity.
- Semantic memory retrieval requires a locally available Ollama embedding model. When embeddings cannot be generated, lexical retrieval is used instead. Existing memories are embedded lazily as they are searched; newly added or edited memories are indexed in the background.
- External service management is a generic HTTPS REST interface using optional bearer tokens and user-granted read/write scopes. Provider-specific OAuth flows, webhook subscriptions and ready-made service adapters (for example Gmail/Slack) are not included. Only GET and POST are supported, and calls require explicit user action.
- PDF/DOCX ingestion and semantic document chunk retrieval are not included.
- The OpenAI-compatible adapter targets the common `/chat/completions` interface; provider-specific extensions may differ.
- The app does not include speech synthesis/recognition or a finished custom VRM character asset. SpeechEngine here means text style and response shaping.
- Proactive topics are generated by the selected LLM and appear inside the app; no ready-made email, SMS or external messaging integrations are present.
- Full packaging/build must be performed on a machine with dependencies installed and the target platform toolchain.

## Data and backups

Use the in-app Export action to create a JSON backup. SQLite is stored in Electron's `userData/mephisto/mephisto.sqlite` directory.


## Desktop application tasks (v0.5.0)

Mephisto can launch explicitly registered desktop applications and request that it close applications it launched during the current Mephisto session. Open **System Tasks**, enable **Desktop application control**, and add an application using the operating-system file picker. The application name is also the chat command alias. You can then ask, for example, `Chrome را باز کن` or `Calculator را ببند`; Mephisto presents a confirmation before acting.

Supported registration: Windows `.exe`, macOS `.app` bundles, and executable files on Linux. Launching uses fixed executable paths with no shell and no user-supplied command-line arguments. Mephisto does not offer arbitrary shell execution, process discovery, or closing unrelated processes. On non-macOS systems, closing is limited to the process Mephisto launched in the current session; on macOS, a registered app launched by Mephisto receives a normal AppleScript quit request. Process tracking is in-memory and is reset when Mephisto exits.

The permission is disabled by default. App registration, launch, close, and removal require the explicit desktop automation permission.
